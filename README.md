# Isaac Carrillo – Security Portfolio

This repository contains hands-on cybersecurity labs demonstrating practical skills in:

- Security monitoring & detection engineering
- Incident response simulation
- Threat modeling
- Cloud security review
- Network traffic analysis
- Active Directory lab configuration

The goal of this portfolio is to showcase real-world security thinking applied to both enterprise lab environments and a production-style SaaS application (MemoryTrap).

---

## 🔐 MemoryTrap Security Labs

MemoryTrap is a mobile flashcard application used as a real-world system to demonstrate:

- Data classification & access control review
- Security logging & detection design
- Incident response tabletop simulation
- Threat modeling (STRIDE-based)
- Cloud security hardening

These labs simulate how a SOC analyst would monitor, detect, and respond to threats in a live SaaS environment.

---

## 🖥 Active Directory Lab

Simulated enterprise environment including:

- Domain controller setup
- Windows client configuration
- Authentication testing
- Network segmentation

---

## 🌐 Traffic Analysis

Hands-on packet inspection and anomaly identification using tools such as:

- Wireshark
- TCP analysis
- Protocol inspection

---

## 🎯 Objective

This portfolio demonstrates the ability to:

- Think like an attacker
- Design measurable detection logic
- Triage and respond to security alerts
- Document security workflows clearly
- Apply security principles to real systems
